QUICK COMMANDS

Setup:
  cd agentic-loan-approval-system
  python -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt
  cp .env.example .env

Run Backend:
  cd backend
  uvicorn app.main:app --reload --port 8000

Run Frontend:
  cd frontend
  streamlit run main.py

Run Tests:
  pytest -v
  pytest tests/test_loan_service.py -v

Test API:
  curl http://localhost:8000/health
  curl http://localhost:8000/loans/stats

Database:
  mysql -u root -p loan_approval_db
  docker run --name loan-mysql -e MYSQL_ROOT_PASSWORD=root \
    -e MYSQL_DATABASE=loan_approval_db -p 3306:3306 -d mysql:8.0

================================================================================
TROUBLESHOOTING
================================================================================

Database Connection Error:
  - Check DATABASE_URL in .env
  - Ensure MySQL is running
  - Verify credentials

Import Errors:
  - Add project to PYTHONPATH: export PYTHONPATH=$PYTHONPATH:.
  - Run from project root directory
  - Check virtual environment activation

Port Already in Use:
  - Change port in command or .env
  - Kill process: lsof -ti:8000 | xargs kill -9

Streamlit Not Loading:
  - Clear cache: rm -rf ~/.streamlit ~/.cache
  - Check frontend/main.py imports
  - Verify API connection
