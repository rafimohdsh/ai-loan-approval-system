WORKFLOW ARCHITECTURE
================================================================================

BEFORE (Broken):
User → API → LoanService.create_decision() → Hardcoded Rules → DB

AFTER (Fixed):
User
  ↓
API (/loans/apply)
  ↓
OrchestrationService.process_loan_application()
  ↓
LangGraph Workflow Execution
  ├─ Node 1: Analyze Loan
  │   └─ Profile Agent (analyze_applicant)
  │       ├─ Income analysis
  │       ├─ Employment assessment
  │       └─ Risk factors identification
  │
  ├─ Node 2: Evaluate Credit
  │   └─ Risk Agent (calculate_risk)
  │       ├─ DTI calculation
  │       ├─ Credit risk assessment
  │       └─ Loan risk evaluation
  │
  ├─ Node 3: Compliance Check
  │   └─ Validates profile and credit data
  │
  └─ Node 4: Final Decision
      └─ Decision Agent (make_decision_mock)
          ├─ Analyzes all factors
          ├─ Makes decision (APPROVED/REJECTED/MANUAL_REVIEW)
          └─ Provides reasoning
  ↓
Create LoanDecision Record
  ├─ Decision status
  ├─ Risk score
  ├─ Approval probability
  └─ Audit trail (all workflow messages)
  ↓
Update LoanApplication Status
  ├─ APPROVED / REJECTED / UNDER_REVIEW
  └─ Metadata (risk, probability, timestamps)
  ↓
Return Response to User
