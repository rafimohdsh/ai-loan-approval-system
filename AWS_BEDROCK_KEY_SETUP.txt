HOW TO ADD YOUR BEDROCK KEY
================================================================================

Option 1: Environment Variables (RECOMMENDED for Docker)
─────────────────────────────────────────────────────────
export AWS_ACCESS_KEY_ID="ABCDDDDD"
export AWS_SECRET_ACCESS_KEY="your-secret-key"
export AWS_DEFAULT_REGION="us-east-1"

Option 2: AWS Credentials File
─────────────────────────────────────────────────────────
~/.aws/credentials:
[default]
aws_access_key_id = ABCDDDDD
aws_secret_access_key = your-secret-key

Option 3: IAM Role (RECOMMENDED for Production)
─────────────────────────────────────────────────────────
- Deploy on AWS EC2/ECS with Bedrock permissions
- No credentials needed in code
- Most secure approach
