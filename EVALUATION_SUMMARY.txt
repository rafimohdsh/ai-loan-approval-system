WORKFLOW PIPELINE VERIFICATION
================================================================================

Input:  Loan Application
        ├─ Applicant (name, email, phone, location)
        ├─ Loan Details (amount, type, term_months)
        └─ Financial Data (income, employment, credit_score, debt)

Processing:
        ↓
        [Profile Agent] → ApplicantProfile with risk assessment
        ↓
        [Risk Agent] → RiskProfile with weighted scoring
        ↓
        [Compliance Check] → Data quality validation
        ↓
        [Decision Agent] → LoanDecision (Bedrock LLM + fallback rules)
        ↓
        [Persistence] → Save to database with audit trail

Output: LoanDecision
        ├─ decision: APPROVED/REJECTED/MANUAL_REVIEW
        ├─ confidence: 0.0-1.0
        ├─ reasoning: Natural language explanation
        ├─ risk_score: 0-100
        └─ agent_analysis: Full audit trail with all intermediate steps

Appeal Support:
        ├─ Rejected applications can appeal
        ├─ Manual reviewer can override decision
        ├─ Full history maintained
        └─ All reviewer actions logged
